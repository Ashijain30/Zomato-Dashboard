# Zomato Analytics Dashboard | Power BI & Excel

An exploratory business intelligence project analyzing 10,000 food delivery orders to understand customer ratings, delivery performance, cuisine preferences, and discount utilization using Power BI and Microsoft Excel.

## Project Overview

This project explores food delivery order data to identify trends in customer experience, delivery efficiency, and ordering behavior. The dashboard provides an interactive view of key performance indicators and enables comparisons across cuisines, delivery partners, payment methods, and other available dimensions.

## Tools & Technologies

- **Power BI:** Dashboard development, interactive visualizations, and KPI reporting.
- **Microsoft Excel:** Data inspection, cleaning, and validation.

## Key Metrics

- Total orders analyzed: 10,000
- Average customer rating: 3.0/5
- Average delivery time: Approximately 65 minutes
- Discount utilization: To be verified against the underlying dataset

## Analysis Areas

- Order trends over time
- Customer rating distribution
- Delivery time and delivery partner performance
- Cuisine-level order patterns
- Discount utilization and payment preferences

## Data Preparation

The dataset was inspected for missing values, duplicate orders, data consistency, and appropriate data types before analysis. Date-related inconsistencies require further validation before review-date analysis can be considered reliable.

## Business Questions

1. How do customer ratings vary across delivery partners and cuisines?
2. Which cuisines and categories contribute most to order volume?
3. How does delivery time vary between delivery partners?
4. What proportion of orders use discounts?
5. How do order patterns change over time?
